NIGHT / LINK - HDR 및 Post Processing 구현 안내

이번 변경은 dev 브랜치의 프로토타입 소스에 반영했다.
사용자 요청에 따라 빌드, 실행, 테스트, 화면 캡처와 렌더링 결과 확인은 하지 않았다.
아래 기본값은 시작점이며 실제 밝기와 흐림 정도는 사용자가 실행해 조정해야 한다.

1. 처리 흐름

도시 장면의 도형과 색상
  → 선형 색상으로 변환 + 네온의 발광 강도 적용
  → 화면 크기의 RGBA16F HDR 텍스처에 렌더링
  → 밝은 영역 추출 / 절반 해상도로 축소 / 가로·세로 가우시안 블러
  → 전체 장면도 별도로 축소하고 블러 처리
  → 화면 중심에서 가장자리로 갈수록 원본과 흐린 장면을 혼합
  → 블룸 합성 및 비넷 적용
  → 노출 적용 / Reinhard 톤 매핑 / sRGB 인코딩
  → 기본 프레임버퍼에 출력
  → HUD와 글자를 선명하게 덧그리기

HDR은 내부 렌더링 버퍼와 계산 범위를 의미한다.
현재 최종 출력은 일반 SDR 화면용이며 HDR10 또는 HDR 모니터 출력 경로는 포함하지 않는다.

2. 효과별 역할

HDR / Tone Mapping
- RGBA16F 버퍼는 1.0을 넘는 색상 에너지를 보존한다.
- 기존 팔레트는 sRGB 값으로 해석하여 선형 색상으로 변환한다.
- Color::Emissive(intensity)는 선형 색상에 (1 + intensity)를 곱한다.
- 네온 창문, 간판, 장치 표시, 차량 조명과 플레이어 바이저 등에 발광 값을 부여했다.
- 밝은 색이 저장 단계에서 잘려 나가기 전에 블룸을 계산한다.
- 마지막에 노출과 Reinhard 톤 매핑으로 출력 범위에 압축한다.
- GL_FRAMEBUFFER_SRGB는 끄고 합성 셰이더에서 한 번만 sRGB로 인코딩한다.

Bloom
- 오브젝트 주위에 반투명 원을 겹쳐 그리던 Renderer::Glow와 그 호출을 제거했다.
- 건물 바닥에 광채를 흉내 내던 중첩 도형도 제거했다.
- 장면에는 창문, 간판, 전조등, 장치 발광 면 등 실제 광원 모양만 그린다.
- 장치 선택 링과 라벨에는 추가 발광값을 부여하지 않는다.
- 광원 주변 번짐은 아래 후처리 블룸에서만 생성한다.
- HDR 장면에서 밝기 임계값을 넘는 영역을 추출한다.
- 밝기는 RGB 채널의 최댓값을 사용하여 청록색과 자홍색 네온도 추출한다.
- Soft knee로 임계값 부근의 기여량이 갑자기 달라지지 않게 한다.
- 가로와 세로 각각 9탭 가우시안 블러를 3회 반복한다.
- 흐린 빛을 원본 장면에 더해 주변으로 번지는 느낌을 만든다.
- 정전으로 발광이 사라진 건물은 블룸 소스도 줄어든다.
- B로 블룸을 끄면 원래 발광 면은 남고 주변의 블룸 번짐은 사라진다.
- 블룸은 화면상 빛 번짐이며 주변 바닥이나 벽을 실제로 비추는 조명 계산은 아니다.

Vignette
- 화면 중심은 유지하고 가장자리로 갈수록 부드럽게 어둡게 한다.
- 시작 위치, 종료 위치, 최대 강도를 각각 조절할 수 있다.

Edge Blur
- 전체 장면을 별도의 텍스처에서 블러 처리한다.
- 가로·세로 9탭 블러를 2회 반복한다.
- 원본 장면과 흐린 장면을 중심 거리 마스크로 혼합한다.
- 중심은 선명하게 남고 화면 양옆과 모서리로 갈수록 흐려진다.
- 깊이 버퍼를 이용한 피사계 심도 효과가 아니라 화면 위치에 따른 주변부 블러이다.
- 블룸과 전체 장면 블러는 다른 텍스처를 사용하므로 서로 켜고 끌 수 있다.

UI
- Renderer::BeginOverlay()에서 도시 후처리를 끝낸 뒤 HUD를 그린다.
- 임무, 조작법, 지도, 상태 알림과 일시 정지 문구에는 블룸·비넷·블러를 적용하지 않는다.

3. 실행 중 조절

O       전체 후처리 켜기 / 끄기. OFF는 기존 직접 렌더링 경로이다.
B       블룸 켜기 / 끄기
V       비넷 켜기 / 끄기
F       가장자리 블러 켜기 / 끄기
[ / ]   노출 감소 / 증가 (0.10씩)
, / .   블룸 강도 감소 / 증가 (0.05씩)
1 / 2   비넷 강도 감소 / 증가 (0.05씩)
3 / 4   가장자리 블러 혼합 강도 감소 / 증가 (0.05씩)

각 조절 키는 한 번 누를 때 한 단계씩 바뀐다.
현재 상태와 강도는 오른쪽 패널 및 알림으로 표시한다.
전체 후처리가 꺼져 있으면 개별 효과를 켜도 최종 화면에는 적용되지 않는다.
개별 효과를 꺼도 설정한 강도는 유지하며, 다시 켜면 해당 값으로 적용한다.
후처리 설정은 이번 버전에서는 저장 파일에 기록하지 않고 재실행 시 기본값으로 돌아간다.

4. 기본값과 코드 조절 위치

SimpleGame/PostProcessor.h의 PostProcessingSettings에서 기본값을 변경한다.

enabled              true
bloom                true
vignette             true
edgeBlur             true
exposure             1.15
bloomStrength        0.38
bloomThreshold       1.00
bloomKnee            0.50
bloomRadius          1.60
vignetteStrength     0.40
vignetteStart        0.35
vignetteEnd          1.35
edgeBlurStrength     0.80
edgeBlurStart        0.48
edgeBlurEnd          1.16
edgeBlurRadius       2.20

중심 거리 마스크는 중심이 0, 각 변의 가운데가 1, 모서리가 약 1.414이다.
start를 높이면 중심의 선명한 영역이 넓어진다.
end를 낮추면 가장자리에서 최대 효과에 더 빨리 도달한다.
radius는 절반 해상도 텍스처의 픽셀 기준이며 수치가 높을수록 더 넓게 퍼진다.
strength는 효과의 혼합량을 조절한다. 블러의 퍼지는 폭과는 다른 값이다.

5. 파일 구성

PostProcessor.h/cpp
  HDR 프레임버퍼, 필터용 텍스처, 후처리 패스와 설정 관리.

ShaderProgram.h/cpp
  도형 및 후처리 셰이더의 공통 파일 읽기, 컴파일과 링크 오류 처리.

Renderer.h/cpp
  HDR 장면과 HUD 렌더링 단계 구분, 발광 속성 전달, 후처리 호출.

Shaders/SolidRect.vs 및 SolidRect.fs
  장면 색상의 선형 변환과 발광값 적용. HUD와 직접 출력에서는 기존 색상 사용.

Shaders/Fullscreen.vs
  전체 화면을 덮는 하나의 삼각형 생성.

Shaders/Downsample.fs
  축소 및 부드러운 임계값을 적용한 밝은 영역 추출.

Shaders/GaussianBlur.fs
  두 텍스처를 교대로 사용하여 가로·세로 블러.

Shaders/Composite.fs
  주변부 블러, 블룸, 비넷, 노출, 톤 매핑과 최종 sRGB 출력.

6. 자원과 실패 처리

- 창 크기가 달라지면 HDR 및 필터 버퍼를 새 크기로 다시 만든다.
- 같은 크기의 버퍼가 이미 준비되어 있으면 재할당하지 않는다.
- 텍스처에는 GL_CLAMP_TO_EDGE를 적용해 화면 반대편의 색이 가장자리로 섞이지 않게 한다.
- 렌더링 대상과 입력 텍스처는 각 필터 패스에서 분리한다.
- 꺼진 효과의 필터 계산은 생략하며, 초기화되지 않은 텍스처를 읽지 않는다.
- 후처리 셰이더 로딩이나 프레임버퍼 생성 실패 시 콘솔에 이유를 기록하고 직접 렌더링으로 전환한다.
- 후처리가 준비되지 않으면 오른쪽 패널에 POST FX UNAVAILABLE을 표시한다.
- 종료 시 텍스처, 프레임버퍼, 셰이더와 VAO를 정리한다.
- 전체 후처리를 끄면 관련 렌더링 패스는 생략하지만 빠른 재활성화를 위해 버퍼는 유지한다.
- 필터 버퍼는 가로·세로 절반 해상도이다. 실제 GPU 비용과 품질은 실행 후 판단해야 한다.

7. 빌드 및 직접 비교 시 참고

Visual Studio 프로젝트에 새 C++ 파일과 셰이더 항목을 등록했다.
기존 빌드 후 복사 규칙이 Shaders/*.vs, Shaders/*.fs 전체를 출력 폴더에 복사한다.
새 셰이더를 포함한 빌드가 완료되어야 이번 효과가 실행 파일에 반영된다.

권장 비교 순서:
1) 같은 장소에서 O로 기존 출력과 전체 후처리 출력을 비교한다.
2) B로 네온 주변 번짐을 비교한다.
3) V와 F를 따로 바꿔 어두워짐과 흐려짐을 구분한다.
4) [ / ]로 전체 밝기를 먼저 맞춘 뒤 각 효과 강도를 조절한다.
5) 정전 복구 전후, 확대·축소, 창 크기 변경 상태를 직접 확인한다.

이번 변경에 대해 빌드, 실행 또는 시각 검증은 수행하지 않았다.
