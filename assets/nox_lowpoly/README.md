# 녹스 로우폴리 모델 팩 v1

후속 리깅·애니메이션과 로봇 몹 7종은 [nox_animated 모델 팩](../nox_animated/README.md)에 있다. 이 폴더는 원래의 정적 모델을 유지한다.

게임 코드와 빌드에 연결하지 않은 모델링 산출물이다. `doc/게임_스토리라인_및_보스_설정.md`의 상시 야간 도시 녹스, 기업 베일, 경찰 감시망을 기준으로 제작했다. 인물의 성별·헤어·색상은 외형 제안이며 확정된 스토리 설정을 변경하지 않는다.

## 파일

| 파일 | 용도 |
| --- | --- |
| `Nox_Modular_Lowpoly.blend` | 편집용 원본. 공용 메시와 연결 복제된 NPC·환경 전시 컬렉션 |
| `meshes/*.glb` | 파트별 독립 모델 42개. 이름·노멀·재질 포함, 외부 텍스처 불필요 |
| `mesh_catalog.json` | 슬롯별 고정 인덱스, 메시 이름, 경로, 삼각형 수, 경계 상자, 재질 및 색상 팔레트 |
| `npc_presets.json` | 주요 인물과 일반 직업을 포함한 14개 외형 프리셋 |
| `preview_npc.png` | 공용 파트로 조립한 14개 외형 미리보기 |
| `preview_environment.png` | 건물 및 자연물·도시 소품 미리보기 |
| `asset_validation.json` | GLB 구조와 삼각형 수, 좌표 유효성, 프리셋 참조 검증 결과 |

## 아트 규격

- NPC 맨몸 기준 높이 1.8m, 머리 높이 0.6m의 3등신. 머리카락은 높이에 추가된다.
- 각진 윤곽, 단면 챔퍼, 평면 노멀을 사용한다. 둥근 자연물도 적은 면으로 구성한다.
- 남녀 머리·상의, 짧은 머리·긴 머리·사이드컷, 일반 의상·갑옷·로봇을 독립 슬롯으로 조합한다.
- 일반 의상은 좁고 단순한 윤곽, 갑옷은 어깨·가슴·무릎 보호대, 로봇은 발광 코어·기계 관절로 구별한다.
- 밤의 도시를 위한 남색·차콜·슬레이트 바탕에 청록·자홍·황색 포인트를 사용한다.
- 자연물은 도시 화단, 녹지 잔존 구역, 버려진 산업 부지에 어울리는 청록 수목·풀과 회색 바위로 구성한다.
- 프리뷰는 형상을 확인하기 위해 밝은 스튜디오 조명을 사용한다. 게임의 야간 조명은 포함하지 않는다.

## 메시 이름과 인덱스

이름 형식은 `SM_NPC_<Slot>_<Index>_<Variant>` 또는 `SM_ENV_<Category>_<Index>_<Variant>`이다.

숫자는 **슬롯 안에서만 유일**하다. 예를 들어 `Head: 1`과 `Hair: 1`은 서로 다른 메시다. 이미 배포한 인덱스는 재번호를 매기지 않고, 새 파트는 새 번호로 추가한다. `0`은 Hair와 Accessory에서만 ‘없음’을 의미한다. 파일 정렬 순서를 인덱스로 사용하지 않는다.

| 슬롯 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| Head | 남성형 | 여성형 | 로봇 | — |
| Hair | 짧은 머리 | 긴 머리 | 사이드컷 | — |
| Torso | 남성형 재킷 | 여성형 재킷 | 갑옷 | 로봇 |
| ArmL | 일반 소매·손 | 갑옷·장갑 | 로봇 팔 | — |
| ArmR | 일반 소매·손 | 갑옷·장갑 | 로봇 팔 | — |
| Legs | 바지 | 갑옷 하의 | 로봇 하체 | — |
| Feet | 부츠 | 장갑 부츠 | 로봇 발 | — |
| Accessory | 바이저 | 데이터 팩 | 진압 방패 | — |

NPC 공용 메시 25개를 사용한다. NPC 한 명당 완성형 메시 파일을 따로 생성하지 않는다. 남녀 구분은 슬롯 조합으로 표현하며, 헤어·갑옷·로봇 파트에 성별 제한을 두지 않는다. 현재 Accessory는 한 번에 한 개를 선택하는 규격이다.

## 좌표와 조립

- 단위는 미터다. 모든 NPC 파트의 원점은 동일한 발밑 `(0,0,0)`이다.
- 파트에는 완성된 몸 안에서의 위치가 이미 들어 있다. 모든 파트를 동일한 이동·회전·배율로 배치하면 조립된다.
- Blender 원본은 Z-up, 정면 -Y, 캐릭터의 왼팔은 +X다.
- GLB는 Y-up, 정면 +Z다. Blender `(x,y,z)`가 GLB `(x,z,-y)`로 변환된다.
- 카탈로그의 경계 상자와 소켓 좌표는 **Blender Z-up 기준**이다. GLB에 적용할 때 축을 변환한다.
- 건물·식물·소품도 지면 기준 원점을 사용한다. 바위 바닥은 지면 아래로 조금 묻히도록 제작했다.
- 라이브러리 컬렉션 `LIBRARY_Parts_OriginAligned`의 원본은 겹쳐 있으므로 숨겨 두었다. 수정할 메시만 표시한다.
- 기본 화면은 `PREVIEW_NPC_LinkedInstances`다. 환경을 볼 때는 이 컬렉션을 숨기고 `PREVIEW_Environment`의 뷰포트·렌더 표시를 켠다.

## NPC별 데이터

`npc_presets.json`의 각 항목은 `npc_id`, 표시 이름, 역할, `parts`, `palette_index`를 갖는다. 각 `parts`에는 위 8개 슬롯의 인덱스가 들어 있다.

| ID | 인물 / 역할 |
| --- | --- |
| ghost | 고스트 / 플레이어 |
| patch | 패치 / 정보 브로커·상인 |
| han_seojin | 한서진 / 수사관 |
| bastion | 바스티온 / 봉쇄반장 |
| blackout | 블랙아웃 / 전력관리자 본인 |
| argos | 아르고스 / 감시국장 |
| administrator | 관리자 / 베일 책임자 |
| hunter_01 | 일반 사냥꾼 |
| raider_01 | 일반 약탈자 |
| hacker_01 | 일반 해커 |
| merchant_01 | 일반 상인 |
| seeker_01 | 일반 탐색자 |
| guard_01 | 일반 경비 |
| service_robot_01 | 정비 로봇 |

일반 직업 6종은 현재 `Society.h`의 직업 이름과 대응한다. 이 파일은 런타임 NPC 전수 명단이나 저장 데이터가 아니다. 후속 작업에서 실제 각 NPC에 프리셋을 배정하거나 선택한 슬롯 인덱스와 팔레트 인덱스를 저장해야 한다.

팔레트는 0 청록 해커, 1 자홍 지하조직, 2 청색 경찰, 3 황색 산업, 4 아이보리 기업이다. 같은 메시의 재질 색상만 바꾼다. GLB에는 기본 재질이 포함되며 팔레트 자동 적용 기능은 없다.

재질 치환 규칙:

- `MAT_Cloth_Navy` → 팔레트 `cloth`
- `MAT_Hair_Base` → 팔레트 `hair`
- `MAT_Skin_Base` → 팔레트 `skin`
- `MAT_Accent_Cyan`, `MAT_Accent_Magenta`, `MAT_Accent_Amber` → 팔레트 `accent`
- 나머지 재질은 기본값 유지

색상 배열은 Blender 셰이더에 지정한 선형 RGB 값이다. Blender 전시용 복제 오브젝트에는 이 팔레트가 이미 적용되어 있다.

## 후속 적용 시 경계

- 현재 정적 모델이다. 본, 스킨 웨이트, 애니메이션, 충돌체, LOD, UV 텍스처는 포함하지 않는다.
- 팔은 좌우가 별도 메시지만 각 팔의 상완·전완은 합쳐져 있다. 다리와 신발도 각각 좌우 한 쌍으로 묶여 있다. 걷기·관절 동작은 후속 리깅 또는 분리 편집이 필요하다.
- 소켓은 리깅 작업을 위한 위치 참고값이며 실제 본이나 제약 조건이 아니다.
- 건물은 외관용이다. 창문·문은 건물 메시에 포함되어 있어 문 개폐나 실내 이동은 별도 편집이 필요하다.
- 하운드의 사족 추적 기체와 블랙아웃의 탑승용 작업 기체는 이 공용 인간형 팩에 포함하지 않았다.
- 한 메시 안에도 재질별 GLB primitive가 존재한다. 메시 공유만으로 드로콜 병합이 완료되는 것은 아니다. 런타임 인스턴싱·재질 배칭은 후속 구현 범위다.
- 원본 게임 소스 수정·컴파일·실행은 수행하지 않았다. 구조 검사와 렌더 미리보기는 모델 산출물만 대상으로 했다.
