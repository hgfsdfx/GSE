# 녹스 오픈 월드 프로토타입

2026-10-20. 기준: [스토리라인 및 보스 설정](게임_스토리라인_및_보스_설정.md).
구현 및 소스 검토까지 진행했으며 빌드, 게임 실행, 렌더링·성능·플레이 검증은 수행하지 않았다.

## 이번 범위

기존 밤 도시, 2.5D 투영, 청크 스트리밍, 스마트폰 자동 전투, 파밍과 구역 보스를 유지한다.
초기 보스 구역은 1,920 × 1,920이며, 생활권은 7개 마을로 확장했다. 그 밖의 절차 생성 도시도 계속 탐험할 수 있다. 상세 배치·거리·주택·소문·이사는 [7개 마을 확장 안내](7개_마을_주택_소문_이사.md)를 참고한다.
활성 청크 반경과 메시 캐시·배치 렌더링 구조는 유지한다.

첫 에피소드의 **자료 확보 → 정전/봉쇄 → 복구 또는 우회 → 귀환/보상**을 간소화해 연결했다.
패치, 고스트, 녹스, 베일, 루멘을 의뢰와 생활권 설정에 반영했다.
마을 7곳과 주민 140명(초기 마을별 20명)이 게임 실행 중 계속 활동한다. NPC 인구가 탐험 거리만큼 무제한 늘어나지는 않는다.

문서의 다섯 보스·전체 결말은 원문 9.3의 후속 범위다. 이번에는 기존 감시자-01 전투를 유지하며
바스티온의 고유 전투나 물리 차단문, 전체 경찰 추격망을 구현했다고 간주하지 않는다.
PK는 단일 플레이어와 NPC, NPC 상호 간 전투다. 네트워크 멀티플레이는 포함하지 않는다.

## 시작과 조작

새 프로토타입은 패치의 은신처 `(90,90)`에서 시작한다.
시작 거점에는 도로를 따라 십자형 광장, 의료소·부품 상점·강화소와 청록색 방어 경계가 표시된다. 각 시설은 기존 T/I/Y/U 마을 거래 기능을 사용한다.
기존 `level_one.save`는 건드리지 않고 실행 파일 옆 `open_world.save`에 별도로 저장한다.
기존 주민 18/36명 저장 파일의 신원과 자산을 유지하면서 140명으로 확장하고 개별 주택을 배정한다. 새 주민 데이터는 `SOCIETY 3` 형식을 사용한다.

| 키 | 기능 |
| --- | --- |
| WASD / Space | 이동 / 달리기 |
| G | 은신처에서 패치의 의뢰 수락·결과 보고 |
| E 길게 | 가까운 중계기·카메라·건물 해킹 |

H는 스마트폰 쿨타임 중이면 공격 1회를 예약한다. 자동 드론 공격보다 예약한 공격을 먼저 처리한다.
J 해제, 일시정지, 창 포커스 상실 시 예약을 취소한다. 플레이어를 추격·공격하는 주민에게는 J/H 없이 스마트폰이 자동 반격한다. 공격 중인 주민을 우선하고 후보마다 사거리와 시야를 확인하므로 가까운 비적대 주민이나 가려진 주민이 반격 대상을 가로채지 않는다. 반격과 드론 공격, H 수동 공격은 같은 스마트폰 쿨타임을 사용한다. 비적대 주민에 대한 선제 공격은 J를 켠 뒤 H로 수행한다. 반격 자체는 현장 수배를 추가하지 않는다.
마을은 거래 거점이며 PK 불가 구역은 아니다. 주민 공격은 수배와 보복을 일으킨다.
NPC는 작업이나 다른 NPC와의 전투 중에도 0.5초 간격으로 플레이어를 감지한다. 약탈 성향 0.7 초과 NPC는 플레이어의 자금·PK 설정과 무관하게 320 거리 안에서 교전을 시작한다. J로 선제 PK를 켜면 사냥꾼과 약탈자도 같은 거리에서 플레이어를 상대한다. 경비는 현장 수배 25 이상일 때 추격한다. 교전 시작 체력 조건은 최대 체력의 40% 이상이며 25% 미만이면 철수한다. NPC의 플레이어 공격 사거리는 160, 쿨타임은 1초이며 시야를 확인한다. 플레이어는 기존 스마트폰 사거리·공격력·쿨타임으로 자동 또는 H 수동 반격한다. 패치는 선제 교전을 시작하지 않는다.
모든 마을 중심 반경 600은 몬스터 차단 구역이다. 몬스터 생성·진입·내부 대상 추격을 막고, 적 발사체는 경계에서 소멸하며 보스 범위 공격도 내부 플레이어에게 피해를 주지 않는다. 몬스터 몸체를 고려해 이동과 생성에 24의 추가 여유를 둔다. 플레이어와 NPC는 자유롭게 출입하며, NPC 사이의 약탈·PK 규칙은 유지한다.

새 마을은 재고 150, 자금 3,000으로 시작한다. 플레이어 자금은 100이다.
시장 상호작용 반경은 600이며, 지도에 금색으로 표시된다.
거점은 생성기가 비워 둔 도로에 배치해 기존 건물이나 길을 막지 않는다.
마을 7곳 모두 중심 반경 760에 걸치는 건물은 생성하지 않아 방어 경계(반경 600) 바깥까지 여유 공간을 확보한다. 건물 전체 충돌 영역과 인접 청크까지 검사하므로 건물 일부만 마을 안으로 돌출하지 않는다. 기존 저장 파일도 다시 불러오면 새 생성 규칙을 적용한다. 중계기·카메라·자료 단말은 독립 시설로 유지하므로 시작 의뢰의 자료 단말 `(235,324)`과 해킹 진행은 그대로 사용할 수 있다.

거래는 마을의 실제 재고·자금과 거래자의 부품·자금을 반대로 증감한다.
상인은 거주 마을에서 물품을 사서 이웃 마을에 운반·판매한다. 재고/자금이 없으면 거래할 수 없다.
의료와 강화는 재고를 소비한다. 사냥·잔해 회수는 부품 공급원이다.
플레이어가 드론을 처치하면 기존 아이템에 더해 거래용 부품 1개와 6 크레딧을 얻는다.
해킹 보수와 첫 의뢰 보수도 사용할 수 있는 지갑에 들어온다.
지갑/시장 자금 상한은 1,000,000, 부품/재고 상한은 10,000이다.

## 주민의 목표와 행동

마을마다 여섯 직업을 섞어 초기 20명을 배치한다. 주민별 개인 주택이 있고 이사 후 소속 인원은 달라질 수 있다. 은신처 상인 중 한 명은 패치다.
패치는 의뢰 거점에 머무르고 다른 상인들은 마을 사이를 이동한다.
주민 정보 패널에서 체력, 자금, 부품, 깨달음, 현재 행동과 성향을 볼 수 있다.

행동 선택은 생존/재산/탐구 가중치와 체력 부족, 보유 자금, 화물, 약탈 가중치를 조합한다.
이동과 상태는 매 업데이트에 반영하되, 일반 작업은 도착 후 약 3초마다 완료하고 다음 목표를 고른다. 휴식과 패치의 거점 작업은 6초다.
초기 작업 시간을 주민별로 분산했다. 상점 왕복이나 사냥터 이동 시간은 이와 별도다.
새 주민과 기존 저장 파일의 비전투 주민은 초기 대기 후 목표를 다시 선택한다. 사냥꾼은 거점 남쪽 780/920/1060 거리의 사냥터를 순환하고, 해커는 마을별 외곽 작업 장소를 순환한다. 탐구자는 다른 마을을 방문하며 경비는 마을의 동서남북을 순찰한다. 상인은 매입·판매 마을을 왕복하고, 매입할 자금이 없으면 사냥·잔해 회수로 부품을 확보한다. 패치는 의뢰를 위해 거점에 남는다.
스트리밍 경계를 넘어도 도로 이동을 계속하고, 로딩된 구역에서는 충돌을 확인한다. 플레이어를 추격할 때는 기존 내비게이션 흐름을 따라 벽을 우회하며, 근거리에서 시야가 막혔어도 이동을 계속한다.

| 직업/행동 | 결과 |
| --- | --- |
| 사냥 | 가까운 실제 드론을 공격, 드론은 공격한 주민에게 반격. NPC 처치는 플레이어 경험치로 가로채지 않음 |
| 잔해 회수 | 거점 남쪽 도로의 사냥터에 도착해 부품 1·깨달음 1 획득, 체력 3 소모 |
| 약탈 | 상대 재산과 거리를 고려해 추격. 약탈자는 기본 약탈 weight 0.95이며 근처 플레이어를 자금 조건 없이 노림 |
| 거래 | 화물 판매 또는 저가 시장 매입 후 다른 마을에 운반 |
| 해킹 | 방문 마을 자금에서 의뢰비 8을 받고 깨달음 2 획득. 현재 작업 구역의 루멘 카메라 교란 반영 |
| 탐구 | 마을에 비용 2를 내고 깨달음 3 획득. 돈이 없으면 느린 독학으로 1 획득 |
| 휴식 | 시장 재고·비용으로 빠르게 회복하거나 자금 부족 시 무료로 천천히 회복 |
| 경비 | 마을에서 드론과 범죄자를 경계, 수배 중인 플레이어 추격 |

깨달음 10마다 NPC 최대 체력 5가 늘며 상한은 180이다. 공격력도 깨달음에 따라 증가한다.
약탈/제압으로 체력이 0이 되면 소지금 절반과 화물이 공격자에게 이전된다.
주민은 사망 처리와 동시에 본인의 거점에서 최대 체력으로 부활한다. 기존 Actor와 신원·직업·깨달음·남은 재산을 유지하므로 주민 수는 140명으로 유지된다. 재산 이전은 사망 한 번당 한 번만 처리하고, 이전 교전의 추격 대상과 경로를 정리한다. 기존 저장 파일에서 부활 대기 중이던 주민도 추가 약탈 없이 즉시 복귀한다.

일반 몬스터는 1초마다 최대 2마리씩 보충한다. 플레이어와 140~470 거리의 도달 가능한 위치를 사용하며, 300 거리 안에 6마리를 우선 확보한다(보스전 중 3마리). 전체 적 수 상한은 18마리, 보스전 중에는 보스를 포함해 9마리다. 마을 중심 624 이내, 벽 안, 다른 적과 45 미만 거리는 생성에서 제외한다. 플레이어가 마을 방어 구역 안에 있으면 보충을 멈춘다. 470보다 멀어진 일반 몬스터는 보충 시 정리해 새 이동 경로에 생성 여유를 확보한다. 보스 처치 후에도 일반 몬스터 보충은 계속되며 보스는 재생성하지 않는다.

한 번의 보충에서 후보 격자를 한 번만 수집하고, 실제 생성 위치 검사는 최대 64회로 제한한다. 생성 가능한 위치가 없으면 다음 보충 주기에 재시도한다. 신규 몬스터의 행동 대기는 0.5초다. 최소 주변 수는 위치 조건과 전체 상한 안에서 우선하는 목표이며, 생성 공간이 부족하면 보장되지 않는다.
주민 간 보복, 저체력 철수, 플레이어를 과도하게 멀리 쫓아가지 않는 제한을 둔다.

현장 수배가 25 이상이면 시장이 거래를 거절하고 가까운 경비가 반응한다.
수배는 게임 시간 초당 1씩 낮아진다. 경비에게서 멀어지고 수배가 진정되면 추격도 해제된다.
HUD의 장기 테러 수배는 현재 서사 표시이며, 별도의 전 도시 경찰 시스템은 후속 범위다.

## 첫 정전 의뢰

1. 은신처에서 G로 의뢰를 받는다.
2. `(116,118)` 중계기 근처에서 E를 길게 눌러 전력을 복구한다.
3. 같은 구역 건물 외부 단말 `(235,324)` 근처에서 E로 자료를 확보한다.
4. 관리자의 함정으로 정전이 발생하고 75초 후 접속 봉쇄가 예고된다.
5. 중계기에서 E로 정상 복구하거나 C로 감시망을 끊고 전력을 우회한다.
6. 은신처로 돌아와 G로 보고하면 조작 기록, 보수 150, 깨달음 10, 경험치 35를 얻는다.

시간을 넘겨도 막다른 상태가 되지 않는다. C 우회 경로로 계속 진행할 수 있다.
완료한 의뢰는 중복 보상을 주지 않으며, 완료·정전·우회 상태를 저장한다.
NPC 해커는 이 사건을 플레이어 대신 해결하지 않도록 첫 거점의 핵심 전력은 건드리지 않는다.

## 구조·저장·성능

- `NpcActor`, `TownActor`, `HouseActor` 모두 SceneGraph의 Actor다. 화면 표시도 Actor 렌더 콜백을 사용한다.
- `Society`는 경제·의뢰·NPC 정책을 담당하고 `LevelOne`은 업데이트 순서와 연결을 맡는다.
- `SocietyAI.cpp`: 행동 선택, 도로 이동, 사냥·약탈·회복.
- `SocietySave.cpp`: 주민 식별자, 위치, 목표, 체력, 재산, 가중치, 의뢰, 시장 상태 저장/검증.
- `PrototypeSociety.cpp`: 마을/주민 렌더링, 시장 안내, 상태 패널과 거점 지도.
- NPC는 스트리밍 청크 자식이 아니라 지속되는 게임플레이 루트 소속이다.
- 화면 밖에서도 인구 140명의 상태가 유지된다. 미로드 구역에서는 예약 도로를 따라 이동하고
  잔해 회수·거래 등을 처리하며, 드론 엔티티와의 전투는 로드된 적이 있는 곳에서 일어난다.
- NPC별 전역 경로 탐색을 추가하지 않았다. 공통 도로 경유 경로와 로드된 곳의 충돌 검사를 쓴다.
- 플레이어 사망 후에도 NPC 상태는 갱신된다. P로 일시정지하거나 게임을 종료하면 멈춘다.
  종료해 둔 시간만큼 진행시키는 오프라인 시뮬레이션은 포함하지 않는다.
- 저장 형식은 `GSE_LEVEL_ONE 3` + `SOCIETY 3`. 이전 `SOCIETY 1/2`도 읽고 주민 수를 확장한다. 임시 객체에 읽고 검증을 마친 뒤 적용한다.
  추격 대상은 실행 중 ActorId 대신 주민 고유 번호로 저장해 재시작 때 연결한다.
- 콘솔 `[Society]`에 주요 사건, 기존 프레임 CSV에 주민 수·지갑·의뢰·거래/약탈/사냥 누계를 추가했다.
  `npc_simulation_ms`는 NPC 갱신 구간이며 그 안의 `scene_update_ms`와 중복 합산하지 않는다.

## 사용자 실행 확인 항목

빌드와 실행은 사용자 담당으로 남겼다. 아래 항목은 아직 실행 검증하지 않았다.

- 새 저장 없이 시작하면 은신처에서 주민과 시장, 새 HUD가 보이는지.
- 30~60초 관찰했을 때 사냥·이동·거래·탐구와 자산/체력 변화가 나타나는지.
- I/Y 거래의 지갑·부품·시장 자금·재고가 함께 변하며 부족할 때 거래를 거절하는지.
- J가 꺼진 상태에서도 적대 사냥꾼·약탈자·경비에게 자동 및 H 반격이 가능한지. 가까운 비적대 주민이나 벽에 가려진 후보가 공격 대상을 가로채지 않는지.
- NPC끼리 전투하거나 작업하던 약탈자가 근처 플레이어에게 교전을 전환하는지. 플레이어 자금이 20 이하인 경우도 같은지. J를 켜면 사냥꾼과의 교전도 시작하고 양쪽 체력이 줄어드는지.
- J/H 선제 공격, 주민 보복, 수배·거래 거절, 사망 시 한 번만 재산 이전, 즉시 거점 복귀·최대 체력·주민 140명 유지가 동작하는지.
- 새 월드와 기존 저장 파일 모두 사냥터 순환, 해커 외곽 이동, 탐구자 마을 방문, 경비 순찰 및 상인 왕복이 나타나는지. 모니터의 현재 위치·목표 위치·작업 시간이 함께 갱신되는지.
- 기존 저장 파일에서 주민이 140명으로 증가하고, 다시 저장·불러오기 후에도 인원과 기존 재산이 유지되는지.
- 시작 마을 광장·시설·방어 경계가 보이며 플레이어와 주민이 자유롭게 출입하는지. 몬스터 추격과 적 발사체는 경계를 넘지 못하고, 내부에서 보스 범위 공격 피해가 없는지.
- 드론 및 주민 간 전투로 사망해도 즉시 부활하는지, 부활 대기 상태의 이전 저장 파일을 불러와도 재산 차감 없이 복귀하는지.
- 연속 사냥·멀리 이동·보스 처치 이후에도 일반 몬스터가 계속 보충되고, 벽이나 마을 중심에 생성되지 않는지.
- 정전 의뢰의 정상 복구와 C 우회, 시간 초과 후 우회, 완료 보상 중복 방지가 동작하는지.
- 멀리 탐험한 뒤 돌아와도 주민 상태가 이어지는지.
- K/Esc 저장 후 다시 실행했을 때 지갑, 시장, 주민, 추격 대상, 의뢰가 복원되는지.
- 같은 빌드 설정·해상도에서 FPS/p95와 `npc_simulation_ms`를 기존 로그와 비교할 것.
